# ЛР1. Реалізація та перевірка зворотного поширення похибки

## Дані та налаштування

- 150 об'єктів, 4 ознаки, 3 класи. Стратифікований поділ 70/30: по 35 об'єктів кожного класу в навчальній вибірці N = 105 і по 15 у тестовій.  `np.random.default_rng(0)`, класи 0, 1, 2, перемішування індексів класу, перші 35 - у навчальну вибірку.
- Середнє та стандартне відхилення обчислено лише на навчальній вибірці і застосовано до обох вибірок.

## 1. Формули та розмірності

Позначення: N = 105, X ∈ ℝ^(105×4), W1 ∈ ℝ^(4×8), b1 ∈ ℝ^8, W2 ∈ ℝ^(8×3), b2 ∈ ℝ^3, Y ∈ ℝ^(105×3) — one-hot матриця міток.

**Прямий прохід**

| Крок | Формула | Розмірність |
| --- | --- | --- |
| Z1 | X·W1 + b1 | 105×8 |
| A1 | max(0, Z1) | 105×8 |
| Z2 | A1·W2 + b2 | 105×3 |
| P | softmax(Z2) | 105×3 |
| L | −(1/N) · Σᵢ log P\[i, yᵢ\] | скаляр |

Втрата обчислюється через log-softmax зі зсувом на максимум

log P = (Z2 − max Z2) − log Σ exp(Z2 − max Z2).

**Зворотний прохід**

| Величина | Формула | Розмірність |
| --- | --- | --- |
| dZ2 | (P − Y) / N | 105×3 |
| dW2 | A1ᵀ · dZ2 | 8×3 |
| db2 | Σᵢ (dZ2)ᵢ | 3 |
| dA1 | dZ2 · W2ᵀ | 105×8 |
| dZ1 | dA1 ⊙ 1\[Z1 \> 0\] | 105×8 |
| dW1 | Xᵀ · dZ1 | 4×8 |
| db1 | Σᵢ (dZ1)ᵢ | 8 |

Для пари softmax + крос-ентропія похідна за логітами одного об'єкта дорівнює P − Y; множник 1/N з'являється через усереднення втрати за об'єктами. Далі діє правило ланцюга: для афінного шару Z = A·W + b градієнт за W дорівнює Aᵀ·dZ, за b - сума dZ за об'єктами, за входом A - dZ·Wᵀ. Крізь ReLU градієнт проходить там, де Z1 \> 0, і обнуляється в інших місцях.

**Які проміжні значення зберігаються з прямого проходу**

- **X** — для dW1 = Xᵀ·dZ1.
- **Z1** — для похідної ReLU, 1\[Z1 \> 0\].
- **A1** — для dW2 = A1ᵀ·dZ2.
- **P та мітки y** — для початкового градієнта dZ2 = (P − Y)/N.
- **W2** — не зберігається в кеші, береться з параметрів; потрібна для dA1 = dZ2·W2ᵀ.

## 2. Звірка з PyTorch

Еквівалентну мережу створено в PyTorch, параметри скопійовано з NumPy-мережі; ваги `nn.Linear` зберігаються як (out, in), тому W1 та W2 транспоновано.

- Втрата NumPy: **1.456200780114282**
- Втрата PyTorch: **1.456200780114282**

Критерій для кожної пари значень: \|a − b\| ≤ 10⁻¹², усі значення скінченні.

| Градієнт b1 | 3.64×10⁻¹⁷ | Так |

Усі перевірки пройдено, тому шукати причину розбіжностей не потрібно.

## 4. Дослід із навмисною помилкою

У зворотному проході прибрано ділення на N у градієнті за логітами: dZ2 = P − Y. Функція втрат, параметри та 105 об'єктів не змінювались, оновлення ваг не виконувалось.

## 5. Висновки

У роботі з нуля на NumPy реалізовано пряме та зворотне поширення для мережі 4 → 8 → 3 з ReLU і крос-ентропією, усередненою за об'єктами. Градієнти обчислено за правилом ланцюга, а для стабільності втрата рахується через log-softmax зі зсувом на максимум. Правильність підтверджено двома незалежними способами: збіг із PyTorch autograd і чисельне диференціювання

Дослід без ділення на N показав, що така помилка не видна за значенням втрати, але всі градієнти стають завеликими рівно в N разів. У реальному навчанні це фактично збільшило б крок градієнтного спуску в N разів. Тому перевірка самих градієнтів, а не лише втрати, необхідна для виявлення помилок у зворотному проході.
